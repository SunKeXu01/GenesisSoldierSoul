# 原始资源恢复审计

## 恢复原则

- 游戏画面、界面、角色、武器、地图、贴图和音效只使用现有资源包中的内容。
- 不再把灰盒、测试场景或缺少材质的场景作为可玩地图发布。
- 新代码只承担浏览器兼容、联网同步和旧资源装载，不替换原游戏美术。
- 每个入口必须同时满足：按钮有原始依据、目标功能存在、所需资源完整。

## 已确认的原页游资源

`创世兵魂素材/创世兵魂` 是目前最接近 4399 原页游缓存的一组资源，而不是后来制作的 Unity 单机仿制包。

- 417 个 SWF：原始大厅、主界面、仓库、战斗 HUD、角色、武器、动画及部分地图资源。
- 577 个 PNG、62 个 JPG、21 个 GIF：武器图标、角色、地图预览及网页素材。
- 172 个 MP3：射击、换弹、击杀、回合播报和环境音效。
- 109 个 `.dfdt` 配置：房间、地图、武器、角色、任务、天梯、战斗规则等。
- `roomConfig.dfdt` 解出 81 条地图定义。
- `version.dfdt` 解出 5731 条原始资源路径及版本映射。

自动提取结果在 `recovery/original-cache`：

- `configs/`：54 个已解压配置，其中 XML 保留原始字段。
- `original-dfdt/`：109 个压缩或 AMF/二进制配置的逐字节副本。
- `maps.json`：81 张地图的编号、中文名、键名、尺寸、天空盒和模型清单。
- `weapons.json`：498 把战斗武器的原名称、模型、弹药、射速、伤害、后坐力、准星、动画和音效参数。
- `manifest.json`：全部已发现资源的大小和 SHA-256。

已从 14 个原始 UI SWF 中无损提取 1342 张位图和 243 个导出界面类，覆盖主界面、大厅、建房、任务、活动、靶场、军团、个人、仓库、商城、战斗和结算。

## Unity 单机包的定位

Unity 包不是原页游客户端本体，但包含从原游戏恢复或重制的可用三维地图、武器和操作资源。它们只作为原始缓存缺失部分的现有资源来源。

- `界面怀旧版（十一月更）`：33 个场景，含自由模式、天梯、生化、建房、房间、工地和足球场等原有流程。
- `单机怀旧创世兵魂V1.2.1`：13 个场景；当前灰色地图和大量空按钮来自此包，不能再作为主版本。
- `离别作`：在上述 13 个场景外增加辐射街区相关场景。
- `六月单机（更新金字塔）`：金字塔更新资源。
- `新工地`、`旧工地重现`、`炼钢厂的前夜`、`生化小镇电脑版`、`迷宫-冰与火之歌`：独立地图来源。

## 当前完整度

原页游的 5731 条版本资源中，扁平缓存可按精确文件名匹配 1602 条。重点类别为：

- UI：23 / 38
- 武器：364 / 737
- 角色：138 / 167
- 地图：31 / 170
- 地图载入图：13 / 86
- 地图缩略图：21 / 70

因此恢复方式必须是“原页游缓存为主，现有 Unity 地图包补齐”，不能继续只围绕一个不完整单机包修补。

## 按钮审计

对“界面怀旧版（十一月更）”的 33 个原有场景进行了实际 Unity 事件审计：

- 共识别 1357 个 `Button`。
- 744 个只绑定 `AudioSource.Play`，即只播放点击音。
- 160 个没有任何持久化回调。
- 4 个存在丢失的脚本目标。

这说明“按钮能按但打不开”来自资源包本身，而非浏览器兼容问题。恢复版不会把这些入口标记为已完成；只按 `UI_FUNCTION_MAP.md` 中已经找到原 SWF 类和配置的功能逐项恢复。
