# REZ 未知后缀确定性画像

日期：2026-08-09

## 结论

为 5 个已有精确停止证据的 REZ 未知后缀增加了固定分窗画像。分析只读取后缀的
首部、中部和尾部各 64 KiB，不搜索内部签名、不跳过当前停止点，也不执行解密、
解压或 carving。5 个后缀在精确起点均不匹配现有受支持格式，但都至少有一个窗口
表现出明显的低熵、零填充、重复块或可压缩结构，因此不能笼统归为随机密文。

| 来源 | 后缀字节 | 首/中/尾熵 | 首/中/尾 zlib 比率 | 分类 |
|---|---:|---|---|---|
| `rez/RB001.REZ` | 21,050,196 | 7.9962 / 3.2021 / 3.0163 | 0.999969 / 0.066864 / 0.258698 | structured/redundant candidate |
| `rez/RF019.REZ` | 1,176,204 | 7.9724 / 0.4618 / 4.8983 | 0.885849 / 0.036041 / 0.460846 | structured/redundant candidate |
| `rez/RF199.REZ` | 2,869,658 | 5.1692 / 3.8182 / 4.8686 | 0.487549 / 0.335175 / 0.450653 | structured/redundant candidate |
| `rez2/RF019.REZ` | 1,661,180 | 7.9752 / 0.4204 / 4.8926 | 0.889359 / 0.033249 / 0.459167 | structured/redundant candidate |
| `rez2/RF199.REZ` | 777,032 | 7.3083 / 4.7978 / 0.0434 | 0.741089 / 0.441010 / 0.004974 | structured/redundant candidate |

其中两份 RF019 的三个窗口曲线高度相似，是下一轮格式对照的优先对象；主
RF199 从首窗开始就具有较强冗余，也优先于 RB001 的高熵起始段。此结论只用于安排
研究顺序，不把统计相似性伪装成已识别格式或已恢复资源。

## 实现与验证

- `tools/recover_private_rez_framed_prefix.py` 新增 `profile_trailing_region()`，清单工具版本升至 16。
- 每个窗口记录熵、零字节比例、可打印 ASCII 比例、zlib 比率和重复 16 字节块比例。
- 同时记录后缀长度的 8/16 字节对齐余数，以及精确起点是否属于现有格式。
- 空后缀、结构化低熵数据、高熵不可约数据、非法边界和非法窗口均有回归测试。
- 专项测试 `34/34` 通过。

画像完成时的下一步是对两份 RF019 做同位置结构差分并寻找可证明的首帧边界；
在边界尚未证明的阶段，5 个后缀均保持原样隔离。后续结果如下。
